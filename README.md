CLI-Bot

CLI-Bot is a command-line tool that captures terminal errors in real time and uses AI to turn them into clear explanations and practical debugging guidance. It helps developers understand and resolve issues directly from the terminal without switching context.

What it does

CLI-Bot runs user commands in a controlled environment, captures output and error streams, and processes stderr data through a structured pipeline. It then classifies errors and optionally sends structured context to an AI model for analysis and response.
